## Learned
- 문자열 내부에 큰따옴표, 작은따옴표를 넣고 싶다면 \ 뒤에 넣기
- \n: 줄바꿈, \t: 탭
- **문자열**
  "문자열" + "문자열": 문자열 연결  
  "문자열" * (상수): 문자열 (상수) 번 반복  
  +=, *= 사용 가능    
  "문자열"[index]: index 위치의 문자 반환  
  "문자열"[:]: 문자열 슬라이싱  
- **문자열 함수**
    len("문자열"): 문자열 길이를 반환
- **연산자** 
  /: 몫  
  //: 몫(소수점 버림)  
  %: 나머지  
  **: 제곱  
- **함수**
  - *입력*  
    input(): 사용자의 입력 str 타입으로 반환
  - *cast*  
    int("str"): 문자열을 정수 타입으로 반환  
    float("str"): 문자열을 실수 타입으로 반환 
    str(data): 다른 자료형을 문자열 타입으로 반환  
  - *문자열*
    "str".upper(), "str".lower(): 대소문자 변환  
    "str".strip(): 양옆 공백 제거, "str".lstrip(): 왼쪽 공백 제거, "str".rstrip(): 오른쪽 공백 제거
    "str".is00(): 문자열 구성 파악하여 boolean 반환
    "str".find("찾는 str"): 특정 문자가 "str"에서 어느 위치에 존재하는지 인덱스로 반환, "str".rfind("찾는 str"): 오른쪽에서부터 찾음
    "찾는 str" in "기반 str": 찾는 str를 포함하면 True, 아니면 False를 반환  
    "str".split("기준 str"): "기준 str" 기준으로 문자열을 잘라 리스트 형태로 반환
    f-문자열: 중괄호 안 문자열이 아닌 타입을 문자열로 바꿔 반환
- mutating, non-mutating 함수 구분하는 법
