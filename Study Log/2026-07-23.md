## Learned
- 전처리를 위한 Compose 메소드는 여러 전처리를 나열하는 역할을 함으로 리스트 형태로 입력 받아야 한다.
- 전공 시간에 CNN의 특징으로 계층적 구조에 대해서 배움 -> 레이어를 거칠수록 이미지의 크기는 줄어들고 채널이 늘어나는 형태 -> Pytorch로 모델을 직접 만드는 도중 Convolution 레이어의 입출력 차원을 조정하는 과정에서 이건 CNN의 본질적 특성이 아님을 깨달음 -> CNN 설계에서 후반 레이어로 갈수록 필터 개수를 늘려야 생기는 특성이었음, 즉 일부러 레이어마다 필터 개수가 일정한 CNN을 설계하면 이미지 크기만 줄어드는 형태를 만들어낼 수 있음 -> 다만 레이어가 깊어질수록 표현력도 일정하면서 성능이 안좋기 때문에 늘렸던 것
- 반대로 Padding을 이용하여 이미지 크기를 유지하면서 채널수만 증가시키는 것도 가능하지만, 연산량 증가, 지역적 파악 등의 문제가 있음
- batch_size 키움 -> 모델이 학습함에 있어 한번에 gradient 업데이트에 있어 더욱 많은 데이터를 반영하여 계산 가능 -> 학습 안정화에 도움이 됨
- lr_scheduler를 사용했더니 갑자기 학습속도가 굉장히 느려져서 loss가 느리게 줄어듦 -> lr_scheduler를 매 iterator마다 작동시키면서 lr이 자주 줄어들어 학습속도가 느려졌던게 원인이었음 -> 일반적으로 epoch 종료 후 나온 vaild_loss를 기반으로 epoch마다 작동해야 학습이 정체되는 곳에서 제대로 lr을 줄일 수 있는 것이었음
- 여태 epoch라 믿었던 학습의 반복이 실은 iter
- epoch : 모델이 전체 훈련 데이터셋을 학습에 사용했을 경우를 1 epoch라 한다
- batch : 한번의 gradient와 parameters 업데이트의 사용되는 전체 데이터셋의 일부를 나타내는 크기   # 여러번의 parameter 업데이트, 메모리 부족 등의 이유로 사용됨
- vaild loss: train dataset의 일부를 때어낸 vaild dataset을 사용했을 때의 loss로 train loss와 그 목적과 계산되는 위치가 다름
